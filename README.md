# 华为多屏协同主题 Windhawk 模组

为 64 位华为电脑管家的 `HwMirror.exe` 窗口提供主题颜色和悬停自动隐藏功能。当前版本：1.18。

- 顶栏与底栏可分别跟随 Windows 应用主题，或选择浅色、深色、自定义颜色。
- 鼠标离开后延迟淡出并收起工具栏，移回手机画面后恢复。
- 包含横竖屏切换、窗口缩放、断开重连时的布局处理。

## 安装

1. 安装并打开 Windhawk，选择「新建 Mod」。
2. 将 `hwmirror-theme.wh.cpp` 的全部内容替换到编辑器。
3. 点击「编译 Mod」并启用；必要时断开后重新连接多屏协同。
4. 在模组设置中调整顶部、底部颜色和自动隐藏时间。

系统主题读取 Windows「设置 → 个性化 → 颜色」中的默认应用模式。关闭模组可恢复原界面。

## 本地编译和回归检查

在 Windows PowerShell 中执行：

```powershell
./scripts/build.ps1
```

默认使用 `C:\Program Files\Windhawk` 的编译器及最新安装的 Engine，也可通过 `-WindhawkRoot` 指定安装目录。构建结果位于 `build/`，脚本同时编译并运行 `tests/check-hwmirror-theme.cpp` 中的隔离回归检查，不会安装或启用模组。

## 兼容性与验证

源码从「查询华为多屏协同深色主题支持」聊天的最终本地文件迁入，针对其中使用的 DuiLib 导出和控件名称编写，仅支持 x86-64。华为软件升级可能改变这些接口。

隔离检查不能替代真实设备验证。加载后请检查主题切换、鼠标进出、手动缩放、横竖屏切换及断开重连。加载失败时可在 Windhawk 高级设置启用日志检查缺失符号。
